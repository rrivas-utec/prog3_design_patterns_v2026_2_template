**unit:** Patrones de diseño

## Indicaciones Específicas
El tiempo límite para la evaluación es 2 semanas.

Cada pregunta deberá ser respondida en un archivo cabecera dentro de `include/` y, cuando corresponda, en un archivo fuente dentro de `src/`:

 - `include/cafeteria.h`
 - `include/gastos_personales.h`
 - `include/sensores_inteligentes.h`  

Si separas las implementaciones, incluye tambien `src/cafeteria.cpp`,
`src/gastos_personales.cpp` y `src/sensores_inteligentes.cpp`, segun corresponda.
El ZIP debe conservar las carpetas `include/` y `src/`. Las definiciones de
plantillas deben permanecer en los encabezados.

Deberás subir estos archivos directamente a www.gradescope.com o se puede crear un .zip que contenga todos ellos y subirlo.
